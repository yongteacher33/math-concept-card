학생용 활동 카드

2A − B에서 무엇이 잘못되었을까?

별명: [내 별명]
A = 3214　B = 1101

행은 가로줄, 열은 세로줄입니다. 각 성분은 행·열 위치에 놓인 수이며, 이 예제의 성분은 단위가 없는 수입니다.

일부러 만든 오답 풀이 · 정답 아님

대각성분에만 2를 곱하고 나머지는 그대로 두었습니다.
잘못된 결과 = 5117

교정 풀이: 네 성분 모두 계산

정답 2A − B = 5327

성분별 검산: (2A − B) + B = 2A

핵심: 실수배는 대각성분만이 아니라 모든 성분에 적용됩니다.

복사가 제한되면 내용이 뜨는 창에서 직접 복사하세요. 인쇄 메뉴에서 PDF로 저장할 수 있습니다.

교사용 해설

교정 풀이와 지도 포인트

1단계 — 실수배: 2A = 6428 입니다. 네 성분 모두에 2를 곱합니다.

2단계 — 같은 위치끼리 뺄셈: 2A−B = [6−1, 4−1; 2−0, 8−1] = [5, 3; 2, 7].

3단계 — 성분별 검산: 5+1=6, 3+1=4, 2+0=2, 7+1=8이므로 2A와 일치합니다.

교사 질문: “대각성분이 아닌 두 칸은 왜 그대로 두면 안 될까?” 네 성분의 위치를 짚으며 설명하게 합니다.

재도전: 숫자 바꾸기

A, B의 네 성분과 실수배 계수를 바꾸고 정답을 계산하거나 답을 확인하세요. 모두 2×2 행렬입니다.

기본 예제의 정답은 [5, 3; 2, 7]입니다.
